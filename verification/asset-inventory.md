# GitHub Asset Inventory

**Scope:** Recursive GitHub tree inventory of every repository visible through the configured GitHub account for **Anomoly247**, **Anom-Originals**, and **Anoms-Hub**. Extensions included: PNG, JPG, JPEG, WEBP, SVG, GIF, and MP4.

> **Raw-file URL pattern:** `https://raw.githubusercontent.com/<owner>/<repository>/<branch>/<path>`. For private repositories, access to a raw URL still requires GitHub authentication with repository permission.

**Flag rule:** A folder is flagged when any asset path contains `glow`, `bling`, `background`, `achievement`, `mood`, `crown`, `potion`, `heart`, or `ghost`. Flagging is filename/path-based and does not claim visual inspection of the artwork.
