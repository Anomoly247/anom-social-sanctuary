It excludes untracked runtime logs and `node_modules`; tracked verification output is included because it contains the literal OAuth startup records.

## Evidence limitations

The database endpoint, current production OAuth base URL, and runtime Forge endpoint are environment/deployment observations. Secrets, database account ownership, object-store bucket name, S3 ACL policy, and Manus control-plane implementation are not present in the repository and are therefore not asserted as facts in this audit.
